# Wood text atlas

`crates/pxui/src/font_atlas.rs` is generated by `crates/pxui/examples/gen_font.rs`; gitignored. Sprite per glyph: `sw, sh, soff, pad_l, pad_t`.

```
cargo run -p fluyer-pxui --release --example gen_font -- <size> <variant>
```
Default `48 7`. Only `size` 16/32/48 are antialiasing-free (1/2/3 mask px strokes).

## Current bake: size 48, variant 7, SCALE 1
- `SIZE 48, ASCENT 36, DESCENT 9, LINE_HEIGHT 45`.
- One mask px = 6 device px = 1 art px (`ART 3` × retina 2), so text and sprites share a grid.
- Three tones inside the mask, rule order: `#502205` where above/left is not ink → `#C17748` where below/right is not ink → else `#6C320F`. Diagonals ignored.
- Silhouette identical to the mask; no outline, no blur, no dither — carving reads as debossed into the plank.

## Variants (kept in the baker)
```
1 flat #502205 body + two-sided lip        2 wall/floor split + bottom lip
3 (2) + top-right glint                     4 balanced external emboss (pads, w+2/h+2)
5 light body + dark outline                 6 dark body + one-sided light lip
7 interior three-role carve (pad 0)         <- current
```
`font::draw_wood` blits through `blit_masked`; `font::draw` is the 1bpp path for plain grey chrome text.

## Traps
- `std::env!("CARGO_MANIFEST_DIR")` paths: assets are `../../assets`, output is `./src`.
- Replaces in the baker silently no-op; verify by parsing the emitted atlas (slice between `= [` and `];`), not by eye.
- `font_atlas::SIZE` must drive every metric (`SCALE`/`LINE_HEIGHT`/`NAME_H`); a hardcoded em halves the layout.
- 2 mask px strokes (em 32) leave no interior: wall eats the whole stroke. Needs 3 px (em 48) for a real floor.
